# 板材設計

Designing with Wood Boards — V2.58

Designing with Wood Boards
板材を切り分け、3Dで組み立て、材料取り図と構想図をA4 1枚にまとめる設計ツールです。HTMLファイルをブラウザーで開いて使えます。



## 材料

材料A：610 × 170 mm、材料B・C：各200 × 170 mm。現在の板厚は12 mmです。木目の向きを確かめながら設計します。



## Step1　材料を切り分ける


- 加工する板・部品を選びます。組み立てに配置済みの部品は、Step2で未配置にしてから加工します。
- 切断方法を選び、「この切断方法を選択する」を押します。
- のこぎり切断では、切断方向を選択し、寸法と切りしろを指定して切断します。切りしろは5 mmまたは10 mmです。

- **のこぎり切断：**直線で切り分けます。仕上がり線や端の丸をドラッグして寸法を調整できます。赤線が仕上がり位置、間の破線が切断位置の目安です。
- **糸のこ盤切断：**点を置いて輪郭を作成します。残す部分を指定して切断を確定します。
- **自在ぎり切断：**中心と直径を指定して円形に加工します。円の中心・円周をドラッグして位置や直径を調整できます。
- **ベルトサンダー加工：** 角を選んで丸めます。半径Rは数値・スライダー・円弧のドラッグで調整できます。

## Step2　部品を配置する

部品一覧のクリックで「配置済み／未配置」を切り替えます。3D上の部品をクリックすると選択され、赤く表示されます。空白をクリックすると選択が解除されます。



| 操作 | 動作 |
| --- | --- |

| 部品を左ドラッグ | 床と平行に移動。近くの端にスナップします。 |

| Shift＋部品を左ドラッグ | Z方向（上下）に移動します。 |

| X・Y・Zキー | 選択した部品を各軸の＋方向へ5 mm移動します。Shiftと同時に押すと−方向です。 |

| X回転・Y回転・Z回転 | 各軸まわりに90°ずつ回転します。角度欄で数値指定もできます。 |

| 指定量だけ持ち上げる | 1〜300 mmの整数で持ち上げます。初期値は選択した板の厚みに連動します。 |

| 接地／Gキー | 床または下にある部品に接する位置まで降ろします。 |

| 空白を左ドラッグ／右ドラッグ | 視点の回転／表示位置の移動。 |

| ホイール・拡大縮小スライダー | 表示を拡大・縮小します。 |

| 右上のキューブ／FIT | 面・辺・角で視点を切り替え／配置した全体を画面に収めます。 |

座標はZ軸が上向きです。部品や仮置き物と重なる移動を制限します。


**仮置き：**右側からCD・文庫・漫画・A4ファイル・A4ノートを追加し、収納できるか確認できます。一覧で配置済み／未配置を切り替え、部品と同じ操作で移動・回転・接地できます。寸法は実物に合わせて変更できます。



## Step3　設計を保存

学年・クラス・番号を0以外に選び、氏名を入力して、設計データをJSON形式で保存します。0のまま、または氏名が空白では保存できません。後から「設計を開く」で編集を再開できます。


設計ファイルの保存後は、Shiftキーを押している間、保存ボタンが「STLで保存」に切り替わります。JSONと同じ名前を引き継いだSTLファイルに板材の形状を出力します。仮置き物はJSONには保存されますが、STLには含まれません。



## Step4　設計＆構想図の作成

「参考にしたもの」に、何のどのアイディアを参考にしたかを120文字以内で記入します。未入力で印刷・PowerPoint出力をしようとすると警告します。


材料取り図を大きく配置し、構想図、参考にしたもの、学年・クラス・番号・氏名、作成日時をA4縦1枚にまとめます。左側にはとじ込み用の余白があります。



- プレビューの構想図をドラッグすると向きを変更できます。Shiftキーは不要です。「構想図を標準の向きに戻す」で戻せます。
- 「A4 1枚で印刷」で印刷し、「PowerPointで出力」でPPTXファイルを保存します。選んだ構想図の向きが反映されます。
- PowerPointでは図は画像、参考にしたものや氏名などは編集できる文字として出力します。

## 新規作成・履歴・自動保存


- **新規作成：**確認後、現在の設計とブラウザー内の自動保存データを新しい設計に置き換えます。履歴も消えるため、残したい設計は先にJSONで保存してください。
- **設計を開く：**保存したJSONを読み込みます。未保存の変更がある場合は確認します。
- **＜ 戻す ＞：**「＜」と「戻す」で操作を取り消し、「＞」でやり直します。
- **自動保存：**設計はブラウザー内に保存されます。別の端末への移動や授業の続きには、JSONファイルを保存してください。

## 動作環境・外部通信

CDN・外部ライブラリは使用していません。3D描画、JSON・STL・PPTXの生成はHTML内で処理します。ローカルファイルとして使う場合、アプリから外部通信は行いません。Web公開版の取得やライセンスリンクを開く際には通信します。詳細は「外部通信・ライセンス」をご覧ください。



## 部品・材料の初期化

Step1の材料取り図で部品名を右クリックし、「この部品を初期化する」を選びます。材料名を右クリックすると、その材料全体を初期化します。「戻す」で取り消せます。

## 起動方法

`index.html` をダウンロードし、ブラウザーで開いてください。ビルドや追加ライブラリのインストールは不要です。

## 氏名等の扱い

学年・クラス・番号・氏名はファイル名から取得します。JSON本文とブラウザーの自動保存には、これらの欄や保存ファイル名を含めません。ファイル名は `学年クラス番号2桁_YYYYMMDD_HHMM_氏名.json` の形式です。

旧形式のJSONに含まれる氏名等も使用しません。ファイル名がこの形式でない場合はStep3で再入力してください。ブラウザーを再読み込みした場合も、設計ファイルを開き直すか再入力が必要です。ファイル名と印刷・PowerPointレポートには氏名等が含まれます。参考にしたもの等の自由記入欄は設計データとして保存します。

Step3には保存ボタンだけを表示します。Step4には上部のタブから移動してください。

## のこぎりの斜め切断

Step1で部品とのこぎり切断を選び、切断方向を「斜め切断」にします。外周上の2点をクリックし、切りしろ（5 mm／10 mm）を確認して「斜めに切断する」を押します。両側が別々の部品として残ります。「2点を選び直す」で指定をやり直せます。外周以外の点、部品の外を横切る線、穴に切りしろが重なる線は使用できません。

## サイズ指定の直方体と斜め切断の寸法

仮置きの「直方体（サイズ指定）」で幅X・奥行Y・高さZを指定できます（各0.1〜5000 mm）。配置後も既存の仮置き物と同じ操作で扱えます。

斜め切断では、選択点・マウス位置から端までの寸法と2点の座標を表示します。「材料図に戻る」と「選択した部品を加工する」で画面を切り替えても2点は維持されます。

斜め切断の2点は仕上がり寸法線を指定します。切りしろはその片側に取り、「指定する仕上がり線」で上側／下側を選べます。下側を選ぶと指定した線の上側に切りしろを取ります。赤い実線が両部品の仕上がり線、薄い赤い帯が切りしろ、中央の灰色破線が切断位置の目安です。

糸のこ盤・斜め切断の指定点は、点をドラッグして修正できます。「一部を切り取る」の両端と斜め切断の2点は外周に沿って移動します。

糸のこ盤切断の角丸半径Rは0が初期値です。ベルトサンダー加工とは半径の設定を分けています。

右上のキューブとFITの間にあるホームボタンで、等角図に戻して配置した全体を画面に収めます。

斜め切断の指定点は1mm刻みに調整します。2点を指定すると、切りしろを除いた残り側の仕上がり位置と寸法を緑色で表示します。
